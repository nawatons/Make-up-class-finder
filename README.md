# ระบบหาวันเรียนชดเชย

หน้าเว็บ (GitHub Pages) + ระบบหลังบ้านเป็น Google Apps Script + ข้อมูลเก็บใน Google Sheet
ใช้ภายในออฟฟิศ 8 คน ข้อมูลทุกคนเห็นตรงกัน อัปเดตอัตโนมัติทุกประมาณ 10 วินาที

**หลักการสำคัญ: ไม่เอาข้อมูลนักศึกษาขึ้น GitHub** ข้อมูลอยู่ใน Google Sheet เท่านั้น
ใน repo นี้มีแค่โค้ด `.gitignore` กันไฟล์ .xlsx/.zip หลุดเข้า repo

## ติดตั้ง (ทำครั้งเดียว ประมาณ 15 นาที)

### 1. สร้าง Google Sheet และระบบหลังบ้าน
1. สร้าง Google Sheet ใหม่ตั้งชื่อ เช่น `BBA Makeup DB` (เปิดสิทธิ์ให้เฉพาะแอดมิน ไม่ต้องแชร์ให้ใคร)
2. เมนู **Extensions > Apps Script** แล้วลบโค้ดเดิม วางเนื้อหาไฟล์ `Code.gs` ทั้งหมด กด Save
3. เลือกฟังก์ชัน `setup` แล้วกด **Run** อนุญาตสิทธิ์ตามที่ขอ (สร้างแท็บ Terms, Sections, Bookings, Cancels, Log)
4. ไปที่ **Project Settings > Script properties** แก้ 3 ค่าที่ขึ้นว่า `CHANGE_ME`
   - `ADMIN_USER` ชื่อผู้ใช้แอดมิน
   - `ADMIN_PASS` รหัสผ่านแอดมิน (ตั้งให้ยาวและเดายาก)
   - `ACCESS_CODE` รหัสเข้าใช้ของออฟฟิศ (ให้พนักงานทั้ง 8 คนใช้รหัสเดียวกัน)
5. กด **Deploy > New deployment** ประเภท **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   - กด Deploy แล้วคัดลอก **Web app URL** (ลงท้าย `/exec`)

> ถ้าติดตั้งเวอร์ชันก่อนหน้าไปแล้ว ให้วาง `Code.gs` ใหม่ รัน `setup` อีกครั้ง (เพื่อเพิ่มคอลัมน์วันที่ในแท็บ Terms) แล้ว Deploy เป็น New version เทอมเดิมที่ยังไม่มีวันที่จะแสดงทุกวันจนกว่าแอดมินตั้งวันที่ให้
>
> ถ้าแก้ `Code.gs` ภายหลัง ต้อง Deploy > Manage deployments > แก้เป็น New version อีกครั้ง URL เดิมจึงใช้โค้ดใหม่

### 2. ขึ้นหน้าเว็บบน GitHub Pages
1. เปิด `index.html` หาบรรทัด `const API_URL='';` ใส่ Web app URL ระหว่างเครื่องหมายคำพูด (หรือปล่อยว่าง แล้วให้แต่ละคนวาง URL ในช่อง "การเชื่อมต่อ")
2. สร้าง repo บน GitHub อัปโหลด `index.html`, `README.md`, `.gitignore` (**ไม่ต้องอัป `Code.gs` ก็ได้** ใช้แค่ใน Apps Script)
3. Settings > Pages > Deploy from a branch > `main` / root
4. ได้ลิงก์ `https://ชื่อผู้ใช้.github.io/ชื่อrepo/` ส่งให้พนักงานพร้อมรหัสเข้าใช้

### 3. นำเข้าข้อมูลรอบแรก (แอดมิน)
1. เปิดเว็บ กรอกรหัสเข้าใช้ กดเชื่อมต่อ
2. เปิดหัวข้อ **ผู้ดูแลระบบ** ล็อกอินด้วย ADMIN_USER / ADMIN_PASS
3. สร้างเทอม เช่น `1-2026` พร้อมระบุ **วันเริ่มและวันสิ้นสุดเทอม** ตารางรายสัปดาห์และการค้นหาจะแสดงเฉพาะช่วงนั้น และระบบหลังบ้านไม่รับการจองนอกช่วงเทอม (แก้วันที่ภายหลังได้ที่ "แก้ไขวันที่ของเทอมที่เลือก")
4. ลากไฟล์ zip ของโฟลเดอร์รายชื่อ (ดาวน์โหลดจาก Google Drive) มาวางในกล่องอัปโหลด

## สิทธิ์
| ใคร | ทำอะไรได้ |
|---|---|
| ทุกคนที่มีรหัสเข้าใช้ | ดูตาราง ค้นหา จอง/ยกเลิกนัดชดเชย ยกเลิก/คืนคาบเรียนปกติ |
| แอดมิน (ชื่อผู้ใช้+รหัสผ่าน) | สร้าง/ลบเทอม นำเข้ารายชื่อ ล้างนัดทั้งเทอม |

ตรวจสิทธิ์ที่ฝั่ง Apps Script ทั้งหมด รหัสผ่านไม่อยู่ในโค้ดหน้าเว็บ ไม่อยู่ใน repo ไม่อยู่ในชีต
ทุกการจอง/ยกเลิกถูกบันทึกในแท็บ `Log` พร้อมชื่อที่ผู้ใช้กรอก (ชื่อเป็นแค่ข้อมูลอ้างอิง ไม่ได้ยืนยันตัวตน)

## ข้อจำกัดที่ควรรู้
- ใครมี URL ของ Web app และรหัสเข้าใช้ก็เข้าได้ ถ้ารหัสหลุดให้เปลี่ยน `ACCESS_CODE` ใน Script properties ทันที
- อัปเดต "เกือบเรียลไทม์" (ดึงข้อมูลทุก 10 วินาที ไม่ใช่ push) ถ้ามีสองคนจองเวลาเดียวกันในช่วงไม่กี่วินาที ระบบจะบันทึกทั้งสอง
- ระบบยังไม่ตรวจห้องเรียนและอาจารย์ผู้สอน
- Google มีโควตาการเรียกใช้ Apps Script ต่อวัน ถ้าเจอข้อความขัดข้องบ่อยช่วงบ่าย ให้ปรับ `10000` ในบรรทัด `setInterval(...)` ของ `index.html` ให้มากขึ้น
- รหัสนักศึกษาเป็นข้อมูลส่วนบุคคล ควรลบข้อมูลเทอมเก่าที่ไม่ใช้แล้ว (ปุ่ม "ลบเทอมนี้")
